PROJECT / 01 GAME PROTOTYPE

GLITCH RUNNER

UNITY  •  C#  •  AUDIO  •  GAMEPLAY

A deliberately frustrating, rage-bait platformer built around precision, rhythm and reactive level design. The experience combines traditional platforming with music-driven gameplay, where the environment responds to the soundtrack and the player is forced to learn patterns, timing and movement.

A major part of the project involved extensive audio implementation and synchronisation, using music as an active gameplay element rather than simply background sound. The stage, effects and gameplay events are designed to work together with the music to create a constantly changing and increasingly chaotic experience.

PROJECT / 02 PROCEDURAL PROTOTYPE

DUNE

UNITY  •  C#  •  PROCEDURAL GENERATION

A reinterpretation of the core gameplay loop from the Dune mobile game, built around rolling up and down a constantly changing desert landscape while attempting to survive for as long as possible.

The project expands the original concept with procedural terrain generation and a darker horror-inspired atmosphere. Instead of simply chasing a high score, the environment gradually introduces narrative elements designed to create tension and make the world feel increasingly unsettling.

PROJECT / 03 GRAPHICS PROGRAMMING

GRAPHICS PROGRAMMING

C++  •  OPENGL  •  3D RENDERING

A low-level graphics programming project focused on understanding how real-time 3D environments are constructed and rendered.

The project involved building a 3D world with interactive objects, camera controls and real-time transformations. One of the central systems is a world containing floating barrels that can be approached, picked up and moved through the environment. Player movement and camera navigation use WASD-based controls, allowing the scene to be explored while interacting with physical objects.

The project explores the underlying programming concepts behind rendering, transformations, cameras, lighting, textures and interactive 3D environments rather than relying entirely on a high-level engine.

02 // PROFILE

ABOUT

I'm a Programmer and Games Design & Programming student with a strong interest in building interactive software, gameplay systems and technically ambitious prototypes.

My work combines programming with practical game development. I enjoy taking an idea from an initial concept through to a working prototype, designing the mechanics, writing the systems behind them and iterating on the final experience.

My current development work spans C#, C++, Unity, Unreal Engine and OpenGL, with particular interest in gameplay programming, mechanics, procedural systems, real-time graphics, interactive environments and technical problem solving.

Alongside programming, my projects involve elements of level design, audio, player experience, prototyping and experimentation. This allows me to approach projects from both the technical implementation and the experience being created for the player.

My goal is to continue developing as a technically capable programmer who can contribute across the development process — from low-level systems and graphics to gameplay mechanics, tools and complete interactive experiences.
