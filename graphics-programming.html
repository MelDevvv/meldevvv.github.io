01 // PROJECT OVERVIEW

UNDERSTANDING
THE RENDERING PIPELINE.

A graphics programming project focused on learning how geometry, shaders, transformations and lighting come together to produce real-time 3D graphics.

This project was built to develop a stronger understanding of low-level graphics programming rather than relying entirely on a game engine's built-in rendering systems.

Using C++ and OpenGL, I worked with the fundamental concepts behind a real-time renderer, including vertex data, buffers, transformations, shaders and the graphics pipeline.

The project provided practical experience with translating mathematical concepts into visual results and understanding how information moves from application code to the GPU.

02 // GRAPHICS

THE RENDERING PROCESS

The project explores the major stages involved in creating a real-time graphical scene and how each stage contributes to the final image displayed on screen.

SYSTEM 01

VERTEX DATA

Defining and managing vertex information used to construct geometry and provide the renderer with the data required to draw objects.

SYSTEM 02

TRANSFORMATIONS

Applying model, view and projection transformations to position objects within a 3D scene and convert their coordinates into screen space.

SYSTEM 03

SHADERS

Using programmable shader stages to control how geometry is processed and how pixels are ultimately rendered to the screen.

SYSTEM 04

LIGHTING

Exploring lighting calculations and how surface properties, light direction and camera position influence the appearance of rendered objects.

SYSTEM 05

3D GEOMETRY

Building and manipulating three-dimensional geometry while working with coordinates, vectors and spatial relationships.

SYSTEM 06

REAL-TIME RENDERING

Combining the individual graphics systems into a real-time rendering loop capable of continuously updating and displaying the scene.

03 // MATHEMATICS
FROM MATH TO PIXELS.

A major part of graphics programming is understanding the mathematics behind the images being produced. This project provided practical experience working with vectors, matrices, coordinates and transformations.

Model, view and projection transformations allow objects to be positioned within a three-dimensional world and ultimately converted into coordinates that can be displayed on screen.

Working directly with these concepts helped develop a stronger understanding of what happens underneath the higher-level rendering systems used by modern game engines.

04 // SHADERS

PROGRAMMING THE GPU

Shaders provide direct control over important parts of the rendering process. The project explores how programmable GPU stages can transform geometry and determine the final appearance of pixels.

VERTEX SHADERS

Processing vertex data and applying transformations before geometry reaches later stages of the pipeline.

FRAGMENT SHADERS

Controlling the final colour and appearance of fragments produced during rasterisation.

UNIFORMS

Passing values such as transformation matrices, camera data and lighting information to shaders.

LIGHTING

Using shader calculations to determine how light interacts with rendered surfaces.

COLOUR

Controlling material and pixel colour through programmable rendering logic.

GPU PIPELINE

Understanding how graphical data moves through the programmable rendering pipeline.

C++ APPLICATION CODE
