01 // PROJECT OVERVIEW

BUILDING THE RENDERING PIPELINE

This project was created to explore the technical foundations behind real-time graphics and interactive 3D applications.

Instead of depending on a complete engine to handle rendering and scene management, I worked directly with C++ and OpenGL to build and understand the individual systems responsible for displaying and controlling a 3D environment.

The project combines programming, mathematics and graphics concepts to create an environment that can be explored through an interactive camera while objects are transformed, rendered, lit and textured in real time.

The work gave me practical experience with the lower-level concepts that sit underneath modern game engines and real-time visual applications.

02 // TECHNICAL SYSTEMS

WHAT I BUILT

The project is made up of several interconnected graphics and interaction systems. Each component contributes to creating a controllable real-time 3D environment.

01 / RENDERING

3D RENDERING

Created and rendered 3D geometry through OpenGL, forming the visual foundation of the interactive environment.

02 / CAMERA

CAMERA CONTROL

Implemented an interactive camera system allowing the environment to be explored and viewed from different positions and orientations.

03 / TRANSFORMS

TRANSFORMATIONS

Used position, rotation and scale transformations to control objects within the 3D scene.

04 / LIGHTING

LIGHTING

Implemented lighting concepts to control how surfaces respond to illumination within the rendered environment.

05 / SHADERS

SHADER PROGRAMMING

Worked with shader-based rendering to control how geometry and surfaces are processed by the graphics pipeline.

06 / TEXTURES

TEXTURE MAPPING

Applied textures to geometry to create more detailed and visually defined 3D surfaces.

03 // DEVELOPMENT

HOW I APPROACHED IT

The project was approached as a technical exploration rather than simply producing a visual scene. The focus was on understanding how each system contributes to the final rendered result.

PROGRAMMING THE SYSTEMS

C++ was used to structure the application and implement the logic responsible for interaction, object behaviour and graphics systems.

WORKING WITH 3D MATHEMATICS

The project required working with the mathematical concepts behind 3D positioning, transformations, rotations and camera movement.

UNDERSTANDING THE GRAPHICS PIPELINE

Working directly with OpenGL provided practical experience with the stages involved in taking geometry and turning it into a rendered image.

ITERATIVE DEVELOPMENT

Features were developed and tested incrementally, allowing individual rendering and interaction systems to be understood before being combined.
