01 // OVERVIEW

ABOUT THE PROJECT

Graphics Programming is a C++ and OpenGL project focused on understanding the technology behind real-time 3D graphics. Rather than relying entirely on a game engine, the project explores lower-level rendering concepts and how different graphics systems work together to create an interactive 3D environment.

PROJECT TYPE

Real-time graphics programming project focused on 3D rendering and interactive graphical systems.

LANGUAGE

C++ with OpenGL and supporting graphics libraries.

DEVELOPMENT

Developed using Visual Studio as a native C++ graphics programming project.

FOCUS

Rendering, transformations, camera systems, lighting, shading, textures and interaction.

02 // TECHNICAL

TECHNICAL IMPLEMENTATION

The project was built around the core concepts involved in constructing and navigating a real-time 3D graphical environment.

3D RENDERING

Rendering 3D objects and constructing an interactive scene using OpenGL.

CAMERA SYSTEM

Real-time camera movement and interaction for navigating the graphical environment.

TRANSFORMATIONS

Position, rotation and scaling of objects through transformation mathematics.

LIGHTING

Lighting systems used to control how objects are visually represented within the scene.

SHADING

Shader-based rendering techniques used to determine the appearance of objects and surfaces.

TEXTURE MAPPING

Applying textures and materials to 3D objects to create more detailed environments.
